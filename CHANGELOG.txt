KLogFilter 버전 이력
====================
버전 규칙: 큰버전.중간버전.빌드날짜시간(yyyyMMddHHmmss). 중간버전은 신규 기능마다 +1.
새 버전을 추가하면 이 파일의 맨 위에 적는다. (시작 화면에는 버전 이름만 표시된다)

Version 1.58 : UP File 탭 처음 목록이 늦게(파일이 많으면 10초 가량) 나오던 문제 수정 — 파일마다 wc·cat 프로세스를 띄우던 것을 head 하나로 여러 파일을 한 번에 읽도록(크기는 목록의 값 사용, 명령 길이 기준으로 묶음). 300개 기준 Windows sh 측정 54.6초 → 0.46초
Version 1.57 : 프로퍼티 창 — 연결된 장치가 바뀌면(Device select에서 고르지 않고 케이블만 바꾼 경우 포함) 읽을 때마다 받는 시리얼(ro.serialno, 없으면 ro.boot.serialno)로 알아채, 이전 장치의 UP 캐시·감시·/LGU_data 기억을 쓰지 않고 두 탭을 처음 읽은 것처럼 다시 채움(장치 차이를 '바뀐 값'으로 표시하지 않음). 안내 줄에 '장치가 바뀌었습니다 (이전 → 새)', Device에 실제 시리얼 표시
Version 1.56 : UP File 탭 변경 반영을 더 빠르게 — adb shell 하나를 열어 두고 장치에서 0.2초마다 파일 시각·크기·md5를 비교해 바뀌면 바로 알림(같은 크기·같은 초 변경도), 알림 즉시 바뀐 파일만 읽음. /LGU_data·권한·수정 시간 확인을 adb 한 번으로 묶음. 감시를 띄울 수 없는 장치는 1초 확인으로, 창을 닫거나 프로그램이 끝나면 감시도 끝냄. adb 명령이 멈춰도 제한 시간 뒤에는 돌아오도록 수정
Version 1.55 : UP File 탭 — 한 번 확인한 장치는 창을 열 때 탭을 바로 표시(/LGU_data·권한 확인을 한 번에, 탭은 확인 즉시), 읽기·Reload는 수정 시간·크기를 확인해 바뀐 파일만 다시 읽음, 자동 갱신이 켜져 있으면 1초마다 확인해 파일이 바뀌면 바로 반영(새 파일·지운 파일 포함, 바뀐 줄 표시는 다음 변경까지). 프로퍼티 창에서 Home/End로 첫 줄/마지막 줄 이동
Version 1.54 : UP File 탭 수정 — Edit(줄 더블클릭)로 선택한 줄의 값을 장치 파일에 고쳐 씀. 값 하나짜리 파일은 파일 내용 전체(여러 줄 가능), key=value 파일은 그 키 줄의 값만 바꾸고 다른 줄·주석·CRLF·끝 줄바꿈 유지. 쓰기 직전에 다시 읽어 고친 뒤 adb push(/data/local/tmp) → 원래 파일에 덮어써 소유자·권한 유지, 다시 읽어 결과 안내. 64KB 초과·읽지 못한 파일은 수정 불가, 권한 없으면 Root 안내
Version 1.53 : 프로퍼티 창(Property·UP File 탭) 값이 칸에 다 보이도록 칸 안에서 줄을 바꾸고 줄(행) 높이를 내용에 맞춰 늘림 (여러 줄 값은 줄마다, 최대 40줄, 열 너비를 바꾸면 다시 맞춤). 필터 일치 노란 바탕은 그대로
Version 1.52 : 프로퍼티 창에 UP File 탭(장치에 /LGU_data 폴더가 있을 때만 보임, 읽을 때마다 확인) — 장치의 /LGU_data/UP 폴더(경로 변경 가능, 설정에 저장) 안 파일을 하위 폴더까지 읽어 "파일 이름 = 값"(두 줄 이상 key=value 파일은 "파일 / key", 64KB 초과는 크기만)으로 Name/Value/Changed 표에, 파일 하나를 지정하면 key=value 줄로. 프로퍼티 탭과 같은 자동 갱신 주기로 다시 읽어 바뀐 줄을 연두색·맨 위·Changed 열로. Filter·Reload·저장 공용, 폴더 없음·권한 없음은 표에 안내
Version 1.51 : 프로퍼티 창 — 갱신에서 값이 바뀐(새로 생긴) 줄을 표 맨 위에 모아 먼저 보여 줌(필터 중에도, 바뀐 값이 있으면 맨 위로 스크롤). 다음 갱신에서 그대로면 원래 순서로
Version 1.50 : 프로퍼티 창 — 이전에 읽은 값과 달라진 줄을 다음 갱신 때까지 연두색으로 표시(5초 뒤 사라지던 방식 대신, 다음 갱신에서 그대로면 지움), 마지막에 Changed 열 추가(바뀐 시각과 '이전 값 → 새 값', 새로 생긴 프로퍼티는 '새로 생김', 줄 툴팁도 같은 내용)
Version 1.49 : 프로퍼티 창·프로세스 창에 Reboot 버튼 — 확인 후 adb reboot, 다시 연결되고 부팅이 끝날 때까지(sys.boot_completed, 최대 3분) 경과 시간을 보이며 기다린 뒤 목록을 새로 읽음. 수집 중·root 상태면 확인 창에 안내
Version 1.48 : 프로퍼티 창·프로세스 창에 Root 버튼 — adb root로 adbd를 root 권한으로 다시 시작하고, 다시 연결되면 목록을 새로 읽음. 지금 권한(root/shell) 표시, 이미 root면 버튼 꺼짐, 판매용 빌드는 안 된다고 안내, 실시간 수집 중이면 끊긴다고 먼저 확인
