KLogFilter 버전 이력
====================
버전 규칙: 큰버전.중간버전.빌드날짜시간(yyyyMMddHHmmss). 중간버전은 신규 기능마다 +1.
새 버전을 추가하면 이 파일의 맨 위에 적는다. (시작 화면에는 버전 이름만 표시된다)

Version 1.41 : .gz 로그 자동 풀기 — Open·Recent·드래그&드롭·실행 인자로 .gz를 열면 같은 폴더(쓸 수 없으면 임시 폴더)에 풀어서 바로 파싱. 이미 푼 파일이 최신이면 그대로 쓰고, .gz가 바뀌었으면 다시 풀어 갱신. 이어 붙인 gz도 끝까지
Version 1.40 :장치 화면 캡처 (F9, View 메뉴, Device select의 버튼) — adb screencap으로 PNG를 받아 실행 폴더에 Screen_날짜_시각.png로 저장, 미리보기 창(다시 캡처·클립보드 복사·다른 이름으로 저장), 수집 중이면 로그에 표시 줄. Linux/macOS용 KLogFilter.sh·build.sh 추가
Version 1.39 : 단축키 정리 — F2 아래 북마크, F3 위 북마크, F4 검색창, Esc 검색 중단·로그 목록으로 (검색 다음/이전은 검색창에서 Enter / Shift+Enter), 로그 목록에서 Tab은 다른 항목으로
Version 1.38 : ADB 연결이 끊기면 기본으로 Stop. '연결 대기' 체크(Run/Stop 옆, File 메뉴)를 켜면 다시 연결될 때까지 기다렸다가 이어서 표시. 끊김·재연결·재부팅 표시 줄과 상태 문구는 영문, 끊김·재연결 줄은 진회색 배경에 흰 글자
Version 1.37 : File > 기록 파일 크기 — adb 기록 파일 하나의 최대 크기 선택 (10·50·100·200·500 MB·1 GB 또는 직접 입력, 기본 100 MB)
Version 1.36 : 엑셀 그래프에 메모리 점유 상위 5개 프로세스 차트 (측정마다 메모리 기준 top을 읽어 기록, '메모리 상위' 시트)
Version 1.35 : 엑셀 저장에 '그래프' 시트 (CPU·메모리·온도 꺾은선 차트, 코어별 선이 켜져 있으면 코어별 차트도 — 셀을 참조하는 실제 엑셀 차트)
Version 1.34 : View 메뉴를 '장치 통계 보기/숨기기' 하나로 (주기·측정 시간·엑셀 저장·자동 저장은 통계 창 안에서)
Version 1.33 : 장치 통계 자세히 창에 측정 시작·종료 버튼 (기본은 측정 안 함 — 옵션을 정하고 '측정 시작', 종료하면 마지막 결과를 남김)
Version 1.32 : 장치 통계 측정 중에는 주기·측정 시간 설정을 흐리게 잠그고, 측정을 끄거나 끝나면 다시 켬. 코어별 체크를 CPU 옆 괄호 안으로
Version 1.31 : 장치 통계 그래프를 측정 전체 기록으로 (시간 눈금, 가로 스크롤 바·마우스 휠로 구간 이동, 간격 1·2·4·8px, 재부팅·오류 표시)
Version 1.30 : 장치 통계 자세히 창의 CPU·메모리·온도 표시 켜고 끄기 (표시 : 체크박스, 그래프 선과 안내 줄·코어별 막대)
Version 1.29 : 장치 통계 그래프에 코어별 CPU 선 (자세히 창의 '코어별' 체크)
Version 1.28 : 장치 통계를 엑셀 파일로 저장 (자세히 창·View 메뉴, 측정 완료 시 자동 저장 — 시각·CPU·메모리·온도·코어별·상위 프로세스)
Version 1.27 : 장치 통계 측정 시간 설정 (View > 장치 통계 측정 시간…, 정한 시간이 지나면 측정을 멈춤)
Version 1.26 : 장치 통계에 CPU 온도 (thermal_zone 센서, 상태 표시줄·자세히 창·그래프)
Version 1.25 : 장치 통계를 이미지로 복사·저장 (자세히 창의 버튼, Ctrl+C)
Version 1.24 : 수집 중 장치 재부팅 표시 (연결이 끊기면 다시 연결해 이어서 수집, 재부팅 시점에 북마크된 표시 줄)
Version 1.23 : 장치 통계 주기 선택 (1·2·5·10·30·60초, View 메뉴 또는 자세히 창)
Version 1.22 : Time 범위에 날짜 (날짜 버튼으로 월-일 시:분:초 선택, 오른쪽 클릭 '이 줄 시각을 Time 시작/끝으로')
Version 1.21 : 안드로이드 장치 통계 (상태 표시줄 오른쪽 CPU·메모리, 누르면 그래프·코어별·상위 프로세스)
Version 1.20 : View 메뉴 Full / Compact 화면 (F12 전환, Compact는 로그 화면만)
Version 1.19 : Find·Remove 정규식 모드 (입력창 오른쪽 .* 버튼, 대소문자 무시)
Version 1.18 : 시간 범위 필터 (Time : 시작 ~ 끝, 예: 12:30 ~ 12:45:30, 10-07 23:00 ~ 10-08 01:00)
Version 1.17 : adb 기록 파일이 50MB를 넘으면 다음 파일(이름_2.txt, _3 …)에 이어서 기록, 화면은 끊김 없이 이어서 표시
Version 1.16 : 입력창별 최근 입력 10개 저장(다음 실행에도 유지), ▼ 버튼·Alt+↓로 골라 쓰기
Version 1.15 : File > 강제 종료 (진행 중인 작업을 기다리지 않고 바로 종료)
Version 1.14 : 메시지 검색 (Ctrl+F, F3 다음 / Shift+F3 이전), 북마크 이동은 F2 / Shift+F2
Version 1.13 : 오른쪽 클릭 → 그 줄의 로그 전체 보기 (줄바꿈, 로그 전체/셀 값 복사)
Version 1.12 : Highlight 입력창 6개, 입력창마다 색상(6가지) 선택
   - 색상은 LogFilterColor.ini의 INI_HIGILIGHT_0~5 (0xRRGGBB)
Version 1.11 : adb 출력을 바로 읽어 표시 (실시간 표시 지연·디스크 사용 감소)
Version 1.10 : 대용량 파일 지원 (읽는 즉시 표시, 메모리 사용 감소), 스크롤 끊김 개선
Version 1.9 : 필터 입력 히스토리(↑/↓), Ctrl+Z/Y 되돌리기, 드래그&드롭·실행 인자로 연 파일 Recent 추가
   - logcat 형식 확장: year, uid, brief, process, tag, dmesg
   - 대용량 로그 성능 개선, 버그·안정성 수정
   - 버전 규칙: 큰버전.중간버전.빌드날짜(yyyyMMddHHmmss)
Version 1.8 : java -jar LogFilter_xx.jar [filename] 추가
Version 1.7 : copy시 보이는 column만 clipboard에 복사(Line 제외)
Version 1.6 : cmd콤보박스 길이 고정
Version 1.5 : Highlight color list추가()

   - ex)INI_HIGILIGHT_COUNT=2
   -    INI_HIGILIGHT_0=0xFFFF
   -    INI_HIGILIGHT_1=0x00FF

Version 1.3 : recent file 및 open메뉴추가

Version 1.1 : Level F 추가

단축키 요약
-----------
[Tag]       Alt+좌클릭 / Alt+우클릭 : 태그를 Show / Remove 필터에 추가
[Bookmark]  Ctrl+F2 또는 더블클릭 : 북마크 토글, F2 : 아래 북마크, F3 : 위 북마크
[Search]    F4 (Ctrl+F) : 검색창으로, Enter : 다음, Shift+Enter : 이전, Esc : 로그 목록으로
[Copy]      Ctrl+C : 선택한 줄 복사, 오른쪽 클릭 : 로그 전체 보기 (로그 전체 복사 / 셀 값 복사)
[View]      F12 : Full / Compact 전환, Tab / Shift+Tab : 로그 목록에서 다른 항목으로
[Device]    F9 : 장치 화면 캡처
자세한 사용법은 docs/USER_GUIDE_*.html을 보세요.
